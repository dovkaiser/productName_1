This guide explains how to install the product.
 
## Prerequisites
 
Before installing the product, make sure you have:
 
- Administrator access
- Internet access
- The installation package
- Another line
 
## Install the product
 
1. Download the installation package.   
   You receive confirmation of the download.
2. Open the downloaded file.
3. Follow the installation wizard.
4. Select **Install**.
5. Select **Finish** when the installation is complete.
 
## Verify the installation
 
Open the application and sign in using your account.   

<details>
<summary>Why can't I push my changes?</summary>

2. Are connected to the correct remote repository.
3. Have permission to push to the repository.
 
</details>

<details>
<summary>Why can't I pull my changes?</summary>
 
Make sure you:
 
1. Have committed your changes.
2. Are connected to the correct remote repository.
3. Have permission to pull to the repository.
 
</details>
