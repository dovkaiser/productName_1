# Product overview

Cloud-based popcorn helps children launch popcorn into space. Many adults use it for the same purpose.

## Introduction

The product uses only *Ecuadorian* popcorn because of its high protein content.

We recommend against using other popcorn varieties. See [Troubleshooting](/docs/troubleshooting.md).

## Key features

The product includes the following features:
- Detects defective popcorn seeds
- Sorts popcorn seeds by size
- Superb launch facility
- Gives aliens something to eat.

## Benefits
- The popcorn enjoys it
- The children enjoy it
- The developers become rich
